# Inventory Management System

A simple web application to manage product inventory, built with Flask, SQLite, and Jinja2.

## Features
- View all products
- Add new products
- Search products by name
- Filter by category
- update stock quantity
- Delete products
- Low stock warning (quantity < 10)

# Tech Stack
- Python 3
- Flask
- SQLite
- Jinja2
- HTML/CSS

## How to Run Locally
1. Clone this respository
2. Install dependencies: 'pip install -r requirements.txt'

4. Open http://127.0.0.1:5000
